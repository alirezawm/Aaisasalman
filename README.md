# شرکت بازرگانی قطعات خودرو آسیا سلمان

یک سیستم مدیریت فروشگاه قطعات خودرو با Flask که برای شرکت بازرگانی قطعات خودرو آسیا سلمان طراحی شده است.

## ویژگی‌های اصلی

### 🔐 سیستم احراز هویت
- ثبت نام و ورود کاربران
- تفکیک کاربران عادی و خریداران عمده
- مدیریت پروفایل کاربری

### 🛒 فروشگاه آنلاین
- نمایش محصولات با فیلترهای پیشرفته
- جستجو بر اساس کد کالا و نام کالا
- فیلتر بر اساس برند و نوع خودرو
- سبد خرید پیشرفته

### 💰 سیستم قیمت‌گذاری
- قیمت‌های مختلف برای خریداران عمده و تکی
- قیمت‌های نقدی و چکی
- تخفیفات ویژه نقدی
- محاسبه اعتبار و بدهی

### 📋 سیستم فاکتور
- ایجاد فاکتورهای حرفه‌ای
- پشتیبانی از پرداخت نقدی و چکی
- بارگذاری مدارک پرداخت
- مدیریت چندین پیش فاکتور

### 👤 داشبورد کاربری
- نمایش آمار خرید
- مدیریت اعتبار و بدهی
- تاریخچه فاکتورها
- بارگذاری مدارک اعتباری

### 🎨 طراحی UI/UX
- طراحی ریسپانسیو با رنگ‌بندی سفید و قرمز
- رابط کاربری روان و زیبا
- سازگار با موبایل و تبلت

### ⚙️ پنل مدیریت
- مدیریت کامل محصولات
- افزودن برندها و انواع خودرو
- مدیریت اطلاعیه‌ها و جشنواره‌ها
- واردات محصولات از اکسل
- مدیریت اطلاعات شرکت

## نصب و راه‌اندازی

### پیش‌نیازها
- Python 3.8+
- pip

### مراحل نصب

1. **کلون کردن پروژه**
```bash
git clone <repository-url>
cd site4
```

2. **نصب وابستگی‌ها**
```bash
pip install -r requirements.txt
```

3. **اجرای برنامه**
```bash
python app.py
```

4. **دسترسی به سایت**
```
http://localhost:5000
```
