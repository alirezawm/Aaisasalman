## 🧠 الگوریتم‌های تشخیص (Detection Algorithms)

### 1. Exact Match (تطبیق دقیق)

```
Input: "لنت ترمز تویوتا"
Cache: {"تویوتا": {"id": 1, "name": "Toyota"}}

Process:
  1. نرمال‌سازی: "لنت ترمز تویوتا"
  2. جستجو در کش: "تویوتا" found ✓
  3. Confidence: 1.0 (100%)

Output: {
  "brand_id": 1,
  "brand_name": "Toyota",
  "confidence": 1.0,
  "method": "exact_match"
}
```

### 2. Fuzzy Match (تطبیق تقریبی)

```
Input: "لنت ترمز تويوتا"  # املای متفاوت
Cache: {"تویوتا": {"id": 1, "name": "Toyota"}}

Process:
  1. محاسبه فاصله Levenshtein
  2. Score: 92/100
  3. Threshold: 85
  4. Match: Yes ✓
  5. Confidence: 0.92

Output: {
  "brand_id": 1,
  "brand_name": "Toyota",
  "confidence": 0.92,
  "method": "fuzzy_match"
}
```

### 3. Regex Pattern (الگوی منظم)

```
Pattern: "(تویوتا|toyota|TOYOTA)"
Input: "TOYOTA Brake Pad"

Process:
  1. اجرای regex
  2. Match found: "TOYOTA"
  3. Mapping به brand_id: 1
  4. Confidence: 0.85

Output: {
  "brand_id": 1,
  "brand_name": "Toyota",
  "confidence": 0.85,
  "method": "regex_pattern"
}
```

### 4. TF-IDF Analysis

```
Input: "قطعات اصلی تویوتا برای کمری"

Process:
  1. Tokenization: ["قطعات", "اصلی", "تویوتا", "برای", "کمری"]
  2. TF-IDF Scores:
     - "قطعات": 0.2
     - "تویوتا": 0.8  ← کلمه مهم
     - "کمری": 0.6
  3. مقایسه با corpus برندها
  4. Best match: Toyota
  5. Confidence: 0.75

Output: {
  "brand_id": 1,
  "brand_name": "Toyota",
  "confidence": 0.75,
  "method": "tfidf"
}
```

### 5. N-gram Matching

```
Input: "تویوتا"
N-grams (n=3): ["تو", "وی", "یو", "وت", "تا"]

Compare with cached n-grams:
  Toyota: ["تو", "وی", "یو", "وت", "تا"]  → 100% match
  Honda:  ["هو", "ون", "ند", "دا"]        → 0% match

Output: {
  "brand_id": 1,
  "brand_name": "Toyota",
  "confidence": 0.7,
  "method": "ngram"
}
```
