# مگاپرامپت نرم‌افزار اندروید - راهنمای استفاده

## فایل‌های ایجاد شده

### 1. `android_app_megaprompt.json`
این فایل شامل یک مگاپرامپت جامع و حرفه‌ای به زبان JSON است که تمام نیازمندی‌های شما برای ساخت نرم‌افزار اندروید را به صورت ساختاریافته و کامل پوشش می‌دهد.

**محتوای این فایل شامل:**
- ساختار کامل پروژه
- نیازمندی‌های فنی و معماری
- سیستم احراز هویت
- ساختار ناوبری و صفحات
- API Endpoints مورد نیاز
- طراحی UI/UX
- نیازمندی‌های عملکرد
- امنیت
- تست و استقرار

### 2. `additional_recommendations_fa.md`
این فایل شامل توصیه‌ها و ویژگی‌های تکمیلی است که می‌تواند به بهبود نرم‌افزار کمک کند.

## نحوه استفاده از مگاپرامپت

### روش 1: استفاده مستقیم با ChatGPT/Claude
1. فایل `android_app_megaprompt.json` را باز کنید
2. محتوای آن را کپی کنید
3. در چت با AI، بگویید: "این یک مگاپرامپت JSON است. لطفا بر اساس آن یک نرم‌افزار اندروید کامل برای من بساز"
4. محتوای JSON را ارسال کنید

### روش 2: استفاده با توسعه‌دهنده
فایل JSON را به توسعه‌دهنده بدهید تا به عنوان سند نیازمندی‌های پروژه از آن استفاده کند.

### روش 3: تبدیل به Prompt متنی
می‌توانید از یک ابزار برای تبدیل JSON به متن استفاده کنید.

## ساختار مگاپرامپت

### بخش‌های اصلی:

1. **اطلاعات کلی پروژه** (`overview`)
   - نام پروژه
   - آدرس وب‌سایت
   - مسیر API

2. **نیازمندی‌های فنی** (`technical_requirements`)
   - نسخه اندروید
   - معماری
   - زبان برنامه‌نویسی

3. **احراز هویت** (`authentication`)
   - روش ورود با شماره تلفن
   - مدیریت Session

4. **ساختار ناوبری** (`navigation_structure`)
   - منوی پایین صفحه
   - 6 تب اصلی

5. **همگام‌سازی داده** (`data_synchronization`)
   - استراتژی همگام‌سازی
   - WebSocket برای به‌روزرسانی لحظه‌ای

6. **صفحه فروشگاه** (`shop_page`)
   - ساختار کامل با تمام بخش‌ها

7. **صفحه دسته‌بندی** (`categories_page`)
   - دو نوع دسته‌بندی (خودرو و برند)

8. **صفحه پروفایل** (`profile_page`)
   - اطلاعات کاربر
   - بخش خریدار عمده

9. **صفحه سفارشات** (`orders_page`)
   - مدیریت سبد خرید
   - فرآیند پرداخت

10. **پنل مدیریت** (`admin_panel_integration`)
    - تمام بخش‌های مدیریتی

11. **نقش‌ها** (`role_based_access`)
    - کارشناس فروش
    - مدیر فروش
    - مدیر سیستم

12. **طراحی UI** (`ui_design_requirements`)
    - رنگ‌بندی
    - فونت‌ها
    - انیمیشن‌ها

13. **عملکرد** (`performance_requirements`)
    - هدف‌های عملکرد
    - بهینه‌سازی

14. **API Endpoints** (`api_endpoints_required`)
    - تمام API های مورد نیاز

15. **ویژگی‌های اضافی** (`additional_features`)
    - اعلان‌ها
    - حالت آفلاین
    - و غیره

## نکات مهم

### قبل از شروع توسعه:

1. **بررسی JSON**: مطمئن شوید که تمام بخش‌ها مطابق نیاز شما است

2. **API Backend**: قبل از ساخت اپ، باید API های مورد نیاز در وب‌سایت پیاده‌سازی شوند

3. **تایید طراحی**: طراحی UI/UX باید تایید شود

4. **مشخصات فنی**: انتخاب تکنولوژی‌ها باید نهایی شود

### موارد اضافی که باید مشخص شوند:

- **رنگ‌های اصلی برند**: در فایل JSON رنگ‌های پیش‌فرض قرار دارد که باید با برند شما مطابقت داشته باشد

- **لوگو و عکس‌ها**: لوگو شرکت و عکس‌های مورد نیاز باید آماده باشد

- **متن‌ها**: تمام متن‌های اپ باید نهایی شوند

- **قوانین کسب‌وکار**: قوانین خاص کسب‌وکار باید اضافه شوند
