# راهنمای پاک‌سازی پروژه - حذف فایل‌های اندروید و فایل‌های اضافی

## 📋 مقدمه

این اسکریپت برای پاک‌سازی کامل پروژه و حذف تمام فایل‌های مرتبط با نرم‌افزار اندروید و فایل‌های اضافی طراحی شده است.

## 🎯 اهداف

- ✅ حذف کامل تمام فایل‌ها و دایرکتوری‌های مرتبط با نرم‌افزار اندروید (Flutter)
- ✅ حذف فایل‌های اضافی و غیرضروری
- ✅ پاک‌سازی فایل‌های بکاپ قدیمی
- ✅ حذف فایل‌های کش و موقت
- ✅ حذف فایل‌های مگاپرامپت قدیمی
- ✅ بهینه‌سازی ساختار پروژه

- `AsiaSalmanApp/` - دایرکتوری اصلی اپلیکیشن Flutter/Android

- تمام فایل‌های `.dart`

## 🚀 نحوه استفاده

### 1. حالت Dry-Run (پیش‌فرض - توصیه می‌شود)

در این حالت فقط لیست فایل‌ها نمایش داده می‌شود و هیچ فایلی حذف نمی‌شود:

```bash
python cleanup_android_and_extras.py
```

### 2. اجرای واقعی

برای حذف واقعی فایل‌ها:

```bash
python cleanup_android_and_extras.py --execute
```

### 3. حالت غیرتعاملی

برای اجرای خودکار بدون درخواست تأیید:

```bash
python cleanup_android_and_extras.py --execute --non-interactive
```

### 4. مشخص کردن مسیر پروژه

```bash
python cleanup_android_and_extras.py --project-root /path/to/project
```

## ⚠️ نکات مهم

### قبل از اجرا:

1. **ایجاد بکاپ**: حتماً قبل از اجرا از پروژه بکاپ بگیرید:
   ```bash
   git commit -a -m "Backup before cleanup"
   # یا
   tar -czf backup_$(date +%Y%m%d).tar.gz .
   ```

2. **بررسی وضعیت Git**: مطمئن شوید که تغییرات مهم commit شده‌اند:
   ```bash
   git status
   ```

3. **اجرای Dry-Run**: ابتدا در حالت dry-run اجرا کنید تا ببینید چه فایل‌هایی حذف می‌شوند:
   ```bash
   python cleanup_android_and_extras.py
   ```

### بعد از اجرا:

1. **بررسی نتایج**: گزارش در فایل `cleanup_report_YYYYMMDD_HHMMSS.json` ذخیره می‌شود
2. **تست پروژه**: مطمئن شوید که پروژه به درستی کار می‌کند
3. **Commit تغییرات**: در صورت رضایت، تغییرات را commit کنید

## 📊 گزارش

پس از اجرا، یک گزارش JSON ایجاد می‌شود که شامل:

- تعداد فایل‌های حذف شده
- تعداد دایرکتوری‌های حذف شده
- حجم فضای آزاد شده (MB)
- لیست فایل‌های حذف شده
- خطاها (در صورت وجود)

## 🔄 بازگردانی تغییرات

در صورت نیاز می‌توانید تغییرات را بازگردانی کنید:

### از Git:
```bash
git checkout .
# یا
git reset --hard HEAD
```

### از بکاپ:
```bash
tar -xzf backup_YYYYMMDD.tar.gz
```
