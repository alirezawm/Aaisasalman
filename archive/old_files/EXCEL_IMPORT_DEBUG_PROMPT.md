# پرامپت حرفه‌ای برای دیباگ سیستم واردات اکسل

## 🎯 هدف
بررسی و رفع مشکل عدم بارگذاری محصولات پس از پردازش فایل اکسل در سیستم بازسازی اکسل

## 🔍 تحلیل مشکل
**مشکل اصلی**: فایل اکسل پردازش می‌شود اما محصولات به دیتابیس وارد نمی‌شوند

## 📋 چک‌لیست دیباگ

### 1. بررسی تنظیمات ورودی
- [ ] آیا گزینه "بازسازی + واردات محصولات" انتخاب شده است؟
- [ ] آیا فایل اکسل شامل ستون‌های مورد نیاز است؟
- [ ] آیا فرمت قیمت‌ها صحیح است (هزار تومان)؟

### 2. بررسی لاگ‌های سیستم
```bash
# بررسی لاگ‌های Flask
tail -f app.log

# بررسی لاگ‌های Python
python -c "import logging; logging.basicConfig(level=logging.DEBUG)"
```

### 3. بررسی مراحل پردازش
1. **خواندن فایل**: آیا فایل اکسل به درستی خوانده می‌شود؟
2. **نگاشت ستون‌ها**: آیا ستون‌ها به درستی نگاشت می‌شوند؟
3. **تبدیل داده‌ها**: آیا قیمت‌ها و موجودی‌ها به درستی تبدیل می‌شوند؟
4. **واردات به دیتابیس**: آیا محصولات به دیتابیس اضافه می‌شوند؟

### 4. بررسی خطاهای احتمالی
- **خطای دیتابیس**: بررسی اتصال به دیتابیس
- **خطای اعتبارسنجی**: بررسی محدودیت‌های فیلدها
- **خطای وابستگی**: بررسی وجود برندها و دسته‌بندی‌ها

## 🚨 خطاهای رایج

### 1. خطای "Product with SKU already exists"
**علت**: محصول با همان کد قبلاً موجود است
**راه‌حل**: بررسی کدهای تکراری یا استفاده از کدهای جدید

### 2. خطای "Brand not found"
**علت**: برند مورد نظر وجود ندارد
**راه‌حل**: ایجاد برند پیش‌فرض یا استفاده از برند موجود

### 3. خطای "Invalid price format"
**علت**: فرمت قیمت صحیح نیست
**راه‌حل**: بررسی فرمت قیمت‌ها (باید عدد باشد)

## 📝 دستورالعمل استفاده

1. **آماده‌سازی**: فایل اکسل را با قالب صحیح آماده کنید
2. **آپلود**: فایل را در بخش بازسازی اکسل آپلود کنید
3. **تنظیمات**: گزینه "بازسازی + واردات محصولات" را انتخاب کنید
4. **پردازش**: روی "شروع بازسازی" کلیک کنید
5. **بررسی**: نتایج را در بخش آمار بررسی کنید
