📋 اطلاعات کلی پروژه:
- نام: شرکت بازرگانی قطعات خودرو آسیا سلمان
- نوع: فروشگاه آنلاین قطعات خودرو
- فریمورک: Flask (Python)
- دیتابیس: SQLite
- زبان: Python 3.11+
- استقرار: Docker + Gunicorn

================================================================================
📁 تحلیل فایل‌های اصلی (Core Application Files)
================================================================================

🔹 app.py - فایل اصلی Flask
   نقش: نقطه شروع برنامه و تنظیمات اصلی
   ویژگی‌ها:
   - پیکربندی Flask app و SQLAlchemy
   - تنظیمات امنیتی و CSRF
   - مدیریت فایل‌های آپلود
   - تنظیمات ISACO warehouse 15
   - بهینه‌سازی SQLite با WAL mode
   - راه‌اندازی Tadbir scheduler
   - فیلترهای تاریخ شمسی
   - Context processor برای notifications
   اهمیت: قلب سیستم - بدون این فایل برنامه کار نمی‌کند

🔹 models.py - مدل‌های دیتابیس
   نقش: تعریف جداول، روابط، و منطق کسب‌وکار در سطح دیتابیس
   مدل‌های کلیدی:
   - User: مدیریت کاربران و احراز هویت
   - Product: محصولات و قطعات خودرو
   - Brand: برندهای خودرو
   - VehicleModel: مدل‌های خودرو
   - PartCategory: دسته‌بندی قطعات
   - Cart: سبد خرید
   - Invoice: فاکتورها
   - UserPoints: سیستم امتیازدهی
   - TadbirSyncLog: لاگ همگام‌سازی با تدبیر
   - ColorScheme: بهینه‌سازی رنگ‌ها
   اهمیت: پایه داده‌ای سیستم - تمام اطلاعات در این مدل‌ها ذخیره می‌شود

🔹 routes.py - مسیرهای وب
   نقش: تعریف تمام URL ها و منطق صفحات وب
   مسیرهای کلیدی:
   - صفحه اصلی و فروشگاه
   - احراز هویت (ورود/ثبت نام)
   - مدیریت پروفایل کاربری
   - سبد خرید و فاکتور
   - پنل مدیریت
   - جستجو و فیلتر محصولات
   - مدیریت برندها و دسته‌ها
   اهمیت: کنترلر اصلی - تمام تعاملات کاربر با سایت از اینجا مدیریت می‌شود

================================================================================
🔧 تحلیل فایل‌های سرویس (Service Files)
================================================================================

🔹 detection_api.py - API تشخیص برند و نوع خودرو
   نقش: ارائه API برای تشخیص خودکار برند و نوع خودرو از متن
   Endpoints:
   - /api/detection/detect: تشخیص تکی
   - /api/detection/batch: تشخیص دسته‌ای
   - /api/detection/stats: آمار تشخیص
   اهمیت: هوش مصنوعی سیستم - کمک به کاربران در پیدا کردن محصولات مناسب

🔹 detection_service.py - سرویس لایه میانی تشخیص
   نقش: مدیریت منطق تشخیص و اعمال threshold های اطمینان
   ویژگی‌ها:
   - تشخیص تکی با threshold
   - تشخیص دسته‌ای
   - مدیریت نتایج
   اهمیت: لایه منطق تشخیص - پردازش و فیلتر کردن نتایج

🔹 brand_vehicle_detector.py - موتور تشخیص برند و نوع خودرو
   نقش: الگوریتم اصلی تشخیص با استفاده از regex و pattern matching
   ویژگی‌ها:
   - تشخیص برندهای خودرو
   - تشخیص انواع خودرو
   - نرمال‌سازی متن فارسی
   - کش کردن داده‌ها
   - مدیریت alias ها
   اهمیت: هسته هوش مصنوعی - الگوریتم اصلی تشخیص

🔹 tadbir_api_service.py - سرویس اتصال به سیستم حسابداری تدبیر
   نقش: همگام‌سازی محصولات، قیمت‌ها و موجودی با سیستم تدبیر
   ویژگی‌ها:
   - احراز هویت با تدبیر
   - دریافت محصولات
   - دریافت قیمت‌ها
   - دریافت موجودی
   - مدیریت token
   - retry mechanism
   اهمیت: اتصال به سیستم حسابداری - همگام‌سازی داده‌ها با سیستم اصلی

🔹 shop_sync_service.py - سرویس همگام‌سازی فروشگاه
   نقش: همگام‌سازی داده‌های فروشگاه با cache تدبیر
   ویژگی‌ها:
   - همگام‌سازی محصولات
   - همگام‌سازی قیمت‌ها
   - همگام‌سازی موجودی
   - مدیریت cache
   - لاگ‌گیری عملیات
   اهمیت: مدیریت داده‌ها - نگهداری همگام‌سازی بین سیستم‌ها

🔹 points_service.py - سیستم امتیازدهی کاربران
   نقش: محاسبه و مدیریت امتیازات کاربران
   ویژگی‌ها:
   - محاسبه امتیاز بر اساس خرید
   - مدیریت جوایز
   - سطح‌بندی کاربران
   - قوانین امتیازدهی
   - انقضای امتیازات
   اهمیت: سیستم وفاداری - تشویق کاربران به خرید بیشتر

🔹 search_engine.py - موتور جستجوی هوشمند
   نقش: جستجوی پیشرفته محصولات با الگوریتم‌های مختلف
   ویژگی‌ها:
   - جستجوی دقیق (exact match)
   - جستجوی بر اساس برند و مدل
   - جستجوی دسته‌ای
   - جستجوی فازی
   - جستجوی معنایی
   - رتبه‌بندی نتایج
   اهمیت: قابلیت جستجو - کمک به کاربران در پیدا کردن محصولات

🔹 persian_date_utils.py - ابزارهای تاریخ شمسی
   نقش: تبدیل تاریخ میلادی به شمسی و فرمت‌بندی
   ویژگی‌ها:
   - تبدیل تاریخ میلادی به شمسی
   - فرمت‌بندی تاریخ‌ها
   - فیلترهای Jinja2
   - پشتیبانی از timezone
   اهمیت: محلی‌سازی - نمایش تاریخ‌ها به صورت شمسی

🔹 database_utils.py - ابزارهای مدیریت دیتابیس
   نقش: مدیریت اتصالات دیتابیس و حل مشکلات lock
   ویژگی‌ها:
   - retry mechanism برای database lock
   - مدیریت transaction ها
   - بهینه‌سازی SQLite
   - WAL checkpointing
   اهمیت: پایداری سیستم - حل مشکلات همزمانی دیتابیس
