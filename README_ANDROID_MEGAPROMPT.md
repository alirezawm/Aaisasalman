# 📱 مگا پرامپت اپلیکیشن اندروید - آسیا سلمان

## 📋 خلاصه

این فایل شامل یک مگا پرامپت حرفه‌ای به فرمت JSON برای ساخت نرم‌افزار اندروید قطعات خودرو آسیا سلمان است.

## 📁 فایل‌ها

- **MEGAPROMPT_ANDROID_APP.json**: مگا پرامپت کامل به فرمت JSON

## 🔌 API Endpoints

مگا پرامپت شامل مستندات کامل تمام API endpoint های مورد نیاز است:

- **Authentication**: ارسال OTP، تایید OTP، Refresh Token، Logout
- **Products**: لیست محصولات، جزئیات، جستجو، فیلترها
- **Categories**: دسته‌بندی‌ها بر اساس خودرو، برند، نوع کالا
- **Discounts**: محصولات تخفیف‌دار روزانه و ماهانه
- **Cart**: مدیریت سبد خرید (افزودن، ویرایش، حذف)
- **User**: پروفایل، درخواست خریدار عمده، اعلان‌ها
- **Company**: اطلاعات شرکت، بنرها
- **App Config**: تنظیمات اپلیکیشن از سرور

## 📱 معماری فنی

- **Pattern**: MVVM (Model-View-ViewModel)
- **Language**: Kotlin
- **UI Framework**: Jetpack Compose + XML
- **Networking**: Retrofit 2 + OkHttp
- **Database**: Room Database
- **Dependency Injection**: Hilt
- **Image Loading**: Glide
- **Pagination**: Paging 3
